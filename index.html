Projeto em destaque

Um caça-níquel 2D jogável, com créditos fictícios, feito para mostrar como renderização, input, animação e estado se conectam.

Jogo 2D · 2026

Selva 777

O resultado de cada giro vem de uma API; o jogo só anima até ele. Os rolos param em sequência, a linha acende e moedas sobem na vitória.

  • PixiJS 8
  • React 18
  • TypeScript
  • Vite
  • WebSocket
  1. RenderizaçãoSprites com texturas pré-geradas, máscara por rolo e blur só quando visível.
  2. InputBotões em React e tecla Espaço disparam ações no estado, nunca direto no canvas.
  3. AnimaçãoTicker do Pixi, easing de parada calculado para não dar solavanco, partículas.
  4. EstadoMáquina de estados: parado, girando, parando, resultado. RTP calculado: 93,9%.
